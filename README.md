# ReviewGamer - Portal de Reseñas de Hardware y Videojuegos

Este es un proyecto web moderno diseñado para entusiastas de los videojuegos y el hardware. Incluye reseñas detalladas de consolas, periféricos (teclados, ratones) y guías técnicas.

## Características
- **Diseño Premium:** Estética oscura con efectos RGB y animaciones fluidas.
- **Catálogo Completo:** Páginas dedicadas para Xbox, PlayStation, Nintendo y accesorios.
- **Guías Informativas:** Contenido sobre DPI, teclados mecánicos y teoría del color.
- **Responsive:** Optimizado para diferentes tamaños de pantalla.

## Tecnologías Utilizadas
- HTML5
- CSS3 (Vanilla CSS con variables y animaciones modernas)
- JavaScript

## Cómo visualizar el proyecto
Simplemente descarga los archivos y abre `index.html` en tu navegador favorito.
