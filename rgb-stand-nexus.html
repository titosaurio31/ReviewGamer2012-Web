Reseña: Stand RGB Nexus

Puntaje Final:8.8/10

El stand Nexus no solo organiza tus auriculares; sirve como un centro de conectividad para tu escritorio con su hub USB integrado y una iluminación base espectacular.

Puntos Fuertes:

  • Hub USB 3.0 de 3 puertos integrado para fácil acceso.
  • Base antideslizante pesada para máxima estabilidad.
  • Modos de iluminación RGB dinámicos que se pueden apagar fácilmente.

Debilidades:

  • El cable de conexión principal es algo corto.
  • La construcción es mayoritariamente de plástico (aunque se siente sólido).
